# ElementraUI Skill — Antigravity Adapter

Google Antigravity natively loads skills from `.gemini/config/skills/` or `<workspace>/skills/`.

## Installation for Antigravity

### Method 1: Global Installation (Recommended)
Copy this entire skill folder to your personal Antigravity skills directory:
- **Windows:** `%USERPROFILE%\.gemini\config\skills\elementraui-skill\`
- **Linux/macOS:** `~/.gemini/config/skills/elementraui-skill/`

### Method 2: Per-Project Installation
Place the `elementraui-skill` directory inside your project:
`<project-root>/skills/elementraui-skill/`

Antigravity will automatically index `SKILL.md` and make the ElementraUI workflow available in paired chat and agent sessions.
